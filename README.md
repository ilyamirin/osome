# Osome: ПВЗ Очередь

Браузерная игра про адскую смену в пункте выдачи заказов маркетплейса `Osome`.

Игрок видит поле `4x5` с очередью клиентов, текущий товар на стойке и должен тапать по клиенту с совпадающим типом заказа. Ошибка сбрасывает комбо и ускоряет рост напряжения. Правильные действия приносят очки, комбо и временные бонусы. По мере игры растут темп спавна, давление шкалы напряжения и частота гиммиков.

## Как Играть

1. Открой страницу игры.
2. Тапни по сцене, чтобы начать смену.
3. Смотри на предмет на стойке.
4. Тапай по клиенту с тем же типом заказа.
5. Избегай ошибок: они сбрасывают комбо и ускоряют рост напряжения.
6. Держи очередь под контролем. Игра заканчивается, когда новая ячейка спавна сверху больше недоступна.

## Геймплей В Текущей Версии

### Базовый цикл

- Клиенты спавнятся сверху по колонкам и падают вниз в свободные места.
- На стойке всегда показан один текущий товар.
- Игрок кликает или тапаeт по клиенту.
- Если тип клиента совпадает с товаром на стойке, клиент уходит.
- Если не совпадает, клиент злится, комбо сбрасывается, давление растет.
- После обслуживания колонка схлопывается вниз.

### Очки И Бонусы

- Базовая выдача: `+10`
- Комбо: `+5` за каждый следующий шаг в серии
- Быстрая реакция: `+3`, если клиент обслужен быстро после входа в зону доступа
- Идеальный ряд: `+20`
- Режим потока после серии без ошибок
- Быстрый старт расширяет зону доступа
- Антистресс срабатывает после серии ошибок

### Гиммики

- `glitch`: верх очереди читается хуже, снимается серией удачных выдач
- `quarrel`: часть ячеек блокируется, конфликт можно погасить выдачей
- `rush`: временно ускоряет спавн

## Баланс И Сложность

Баланс хранится в [balance-config.js](/Users/ilyagmirin/PycharmProjects/Osome/balance-config.js).

Ключевые свойства текущего конфига:

- рост сложности идет шагами по `15_000 ms`
- `glitch` и `quarrel` открываются после `45` секунд
- `rush` открывается после `120` секунд
- к `3` минутам становится тяжело
- к `5` минутам игра близка к потолку сложности

Текущая кривая на симуляции:

- `casual`: около `3:06`
- `solid`: около `3:34`
- `expert`: около `4:08`
- `expert p90`: около `4:57`

## Быстрый Старт

### Требования

- `Node.js`
- `npm`
- любой простой статический сервер

### Установка

```bash
npm install
npm run hooks:install
```

### Локальный запуск

Самый простой вариант:

```bash
python3 -m http.server 8124
```

Потом открой:

```text
http://127.0.0.1:8124/
```

Если на машине `127.0.0.1` не подхватывается из-за конкретной конфигурации сервера, попробуй:

```text
http://localhost:8124/
```

### Полезные примеры

Проверить текущий баланс:

```bash

```

Прогнать сглаживание или варианты:

```bash
npm run balance:simulate -- --runs 180 --smoothStepMs 15000
npm run balance:simulate -- --runs 180 --spawnScale 1.04 --lateSpawnScale 1.06 --tensionScale 0.97 --lateTensionScale 0.98 --orderShift 0.08
```

Поиск кандидатов для балансировки:

```bash
npm run balance:search -- --runs 180
```

## Архитектурные Решения

- Проект специально сделан без фреймворка и без сборки.
- Вся игра живет в одном статическом клиенте: `index.html + styles.css + game.js`.
- Баланс отделен от рантайма в `balance-config.js`, чтобы можно было тюнить сложность без переписывания основной логики.
- Симулятор баланса запускается отдельно в Node и не зависит от браузера.
